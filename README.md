# 💊 Smart Drug Recommendation System

An AI-powered clinical decision support system that recommends safe and personalized medications based on patient symptoms, medical history, and safety constraints.

## 🎯 Features

- ✅ ML-based drug prediction (Random Forest)
- ✅ Allergy verification
- ✅ Drug interaction detection
- ✅ Age contraindication checking
- ✅ Personalized recommendations with confidence scores
- ✅ Safety warnings and explanations

## 🛠️ Tech Stack

- **Backend**: Flask (Python 3.8+)
- **ML**: scikit-learn, Random Forest
- **Frontend**: HTML5, CSS3, Bootstrap 5
- **Database**: CSV files (prototype)
